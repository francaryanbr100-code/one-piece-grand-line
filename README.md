# 🏴‍☠️ One Piece — Grand Line Database

Uma enciclopédia digital inspirada no universo de **One Piece**, desenvolvida como projeto acadêmico de Front-End.

O Grand Line Database permite explorar personagens do universo criado por Eiichiro Oda, consultar suas informações e navegar por uma coleção de personagens de forma simples e interativa.

## ✨ Funcionalidades

- **Listagem de personagens:** exibição de personagens com imagens e informações.
- **Busca:** pesquisa de personagens pelo nome.
- **Filtro por idade:** organização dos personagens por faixas etárias.
- **Carregar mais:** exibição gradual dos resultados.
- **Imagens automáticas:** busca de imagens dos personagens, com algumas imagens personalizadas.
- **Design responsivo:** adaptação para computadores, tablets e celulares.

## 🛠️ Tecnologias utilizadas

- HTML5 — estrutura do site.
- CSS3 — estilização e responsividade.
- JavaScript — funcionalidades, filtros e integração com API.
- API One Piece — obtenção dos dados dos personagens.
- One Piece Wiki — busca de imagens dos personagens.

## 🌐 API utilizada

Os dados dos personagens são obtidos por meio da API:

https://api.api-onepiece.com/v2/characters/en

As imagens são carregadas a partir de fontes personalizadas e da One Piece Wiki.

## 🚀 Como executar o projeto

1. Baixe ou clone este repositório.
2. Abra a pasta `one-piece-grand-line`.
3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server no Visual Studio Code.
4. Certifique-se de estar conectado à internet para carregar os dados e as imagens externas.

## 🎨 Identidade visual

O projeto utiliza uma temática inspirada em mapas, tesouros e cartazes de procurados de One Piece, com uma interface escura e detalhes em dourado.

## 🎓 Projeto acadêmico

Desenvolvido como atividade acadêmica do curso de graduação da UniFECAF, com o objetivo de aplicar conhecimentos de HTML, CSS, JavaScript e consumo de APIs públicas.
